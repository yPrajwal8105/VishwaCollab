📊 Import Sample Data to VishwaCollab

Follow these steps to import sample data into your VishwaCollab database using phpMyAdmin.

Step 1: Open phpMyAdmin

Make sure XAMPP is running and open phpMyAdmin:

http://localhost/phpmyadmin

You should see the phpMyAdmin interface with your databases listed.

Step 2: Select or Create Database

In the left sidebar, look for the vishwacollab database:

  • If it exists, click on it to select it
  • If it doesn't exist, click "New" and create a database named vishwacollab

Step 3: Import SQL File

Once you're in the vishwacollab database:

  1. Click on the "Import" tab at the top
  2. Click "Choose File" or "Browse"
  3. Navigate to your VishwaCollab folder and select vishwacollab_sample_data.sql
  4. Make sure the format is set to "SQL"
  5. Click "Go" or "Import"

Step 4: Verify Import

After import, you should see:

  • ✅ 4 tables created: students, companies, jobs, applications
  • ✅ 10 students with various skills and courses
  • ✅ 10 companies from different industries
  • ✅ 15 job postings with diverse requirements
  • ✅ 15 job applications with different statuses

Step 5: Test Search Functionality

Now you can test the search functionality:

  1. Go to your VishwaCollab home page
  2. Try searching for these terms:
    • "Software" - Shows software developer jobs
    • "Python" - Shows Python-related jobs and students
    • "Tech" - Shows technology companies
    • "Data" - Shows data science jobs and students
    • "React" - Shows React developer positions
⚠️ Important Notes:
  • Make sure XAMPP MySQL service is running
  • If you get errors, check that the database name is exactly "vishwacollab"
  • If tables already exist, the import will add data to existing tables
  • Backup your database before importing if you have important data
🎉 Success!
Once imported, your search functionality will show real results from the database. You can search for jobs, companies, and students with various skills and get relevant matches.
